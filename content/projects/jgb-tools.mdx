## Project Overview

JGB Tools is a free collection of browser tools for messaging a number without saving it, checking whether a website is reachable, making QR codes, downloading YouTube thumbnails, generating passwords, checking a public IP address, compressing images and previewing link metadata. The site is supported by ads and does not require an account. Most tools process data in the browser; server-backed tools explain what they send.

## The Challenge

Small tasks often require visiting sites with unclear data handling or account requirements. JGB Tools makes each tool's purpose and data handling clear, and keeps processing on the user's device when the task allows it.

## The Solution

JGB Tools is a web application built with **TanStack Start** and **React**, using **TypeScript**, **Tailwind CSS**, **Cloudflare Workers**, **Drizzle** and **Neon Postgres**.

- **Text Anyone:** open WhatsApp, Telegram, Signal, SMS or Viber for a number without saving it to contacts.
- **Is It Down?:** check a website's availability and response time.
- **QR Code Generator:** make QR codes for links, Wi-Fi, messaging, email and contact details; download PNG or SVG files.
- **YouTube Thumbnail Downloader:** get available thumbnail sizes from a YouTube link.
- **Password Generator:** create passwords and passphrases in the browser.
- **What's My IP:** view your public IP address and approximate location.
- **Image Compressor:** compress and resize JPEG, PNG and WebP images in the browser.
- **Link Preview Checker:** inspect link previews for WhatsApp, Facebook, X and Google.

The service is free and ad-supported. There is no sign-up, and most tools run on the device; server-backed tools use the service needed for their task. The site includes guides, privacy information and terms.
