## Project Overview

This website serves as the digital headquarters for JGB Solutions. It is a comprehensive portfolio designed to showcase software engineering expertise, share technical insights through a blog, and provide a direct channel for potential clients and collaborators.

## The Challenge

The site needed to present projects and writing in one place, load fast, and be easy for search engines to index, while being simple to update.

## The Solution

We built the portfolio with **TanStack Start**, using server-side rendering (SSR) for fast first loads and search engine indexing.

- **Stack:** Built with React, TypeScript, and Tailwind CSS for a type-safe, utility-first styling approach.
- **Design:** A light and dark theme, subtle animations and a "glassmorphism" style.
- **Content:** Projects and blog posts are written as MDX files, so adding one is a single file in the repository.
